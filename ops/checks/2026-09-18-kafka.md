## 已完成

- 三台节点已安装 Java 17 和 Kafka 3.9.1。
- 三台节点已使用同一个 KRaft cluster id 格式化日志目录。
- Kafka systemd 服务和 256/512 MiB JVM 验证期内存配置已写入。
- Kafka 二进制下载使用华为云 Apache 镜像，安装脚本不包含凭据。

## 当前状态

Kafka 服务已暂时停止。原因是轻量云防火墙尚未放通三台 S 节点之间的 TCP `9092-9093`，KRaft Controller quorum 无法建立；不在端口放通前让服务持续重启。

放通后执行：

```bash
for host in 10.4.4.2 10.4.4.8 10.4.4.5; do
  ssh ubuntu@$host 'sudo systemctl start kafka'
done
/opt/kafka/bin/kafka-metadata-quorum.sh --bootstrap-server 10.4.4.2:9092 describe --status
/opt/kafka/bin/kafka-topics.sh --bootstrap-server 10.4.4.2:9092 --create --if-not-exists \
  --topic crawler.publication.v1 --partitions 3 --replication-factor 3 \
  --config min.insync.replicas=2
```
