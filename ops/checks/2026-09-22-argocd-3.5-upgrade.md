## Kubernetes 1.37 滚动检查

`kubectl rollout status` 不支持 `--all`。按工作负载类型配合标签选择器检查：

```bash
kubectl rollout status deployment \
  -n argocd \
  -l app.kubernetes.io/part-of=argocd \
  --timeout=300s

kubectl rollout status statefulset \
  -n argocd \
  -l app.kubernetes.io/part-of=argocd \
  --timeout=600s
```

不使用 `kubectl wait pod --all` 验收滚动升级，因为被替换的旧 Pod 消失时会产生误导性的 `NotFound`。
